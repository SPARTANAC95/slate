Automatic update checks are here.

- Slate checks GitHub for new releases on startup and every six hours.
- Open Preferences to check manually, read release notes, or switch automatic checks off.
- Choose **Install and restart** when ready. Slate verifies the download signature, saves pending notes, and makes a fresh calendar backup before installing.
- Download, verification, or backup failures stop installation and let you retry.

**Coming from 0.1.0?** Download and run the 0.1.1 installer once. After that, new releases appear inside Slate. Your existing calendar stays in place.

Updates are delivered by published versioned releases, not every source-code commit. Windows may still show an unknown-publisher warning: update signatures verify Slate releases but are separate from a Windows publisher certificate.
