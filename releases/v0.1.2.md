# A Backlog you can act on

- Add ideas directly in Backlog, with visible Edit, Delete, done, Today, and Choose date buttons.
- Schedule an idea and jump straight to its day. Completed ideas stay in a collapsible section with Undo.
- Open Backlog from Month, Year, or Upcoming; undated Upcoming items are now editable and schedulable too.
- Adding an undated idea no longer opens the panel automatically. Backlog replaces the day panel while open so the calendar keeps its space.
- Fixed Windows HTML drag-and-drop configuration and the clipped date/time form layout. Failed saves now display an error instead of silently appearing to work.

**Update:** In Slate 0.1.1 or newer, open Preferences → App updates → Check for updates, then choose Install and restart. For 0.1.0, run the installer below once. Your existing calendar stays in place.
