## 0.1.2 — 2026-09-23

- Add ideas directly in Backlog, with visible Edit, Delete, done, Today and
  Choose date actions. Scheduling opens the selected day.
- Keep completed ideas in a collapsible section with Undo.
- Open Backlog from Month, Year and Upcoming; edit or schedule undated entries
  from Upcoming too. Adding an undated entry does not force Backlog open.
- Fix Windows drag-and-drop configuration and clipped date/time fields, and
  show failed-save errors.

## 0.1.1

- Add signed in-app updates, automatic checks, release notes and installation
  after confirmation, with a calendar backup before installation.

## 0.1.0

- Publish the Windows app, product website, user and developer guides.
- Include month, upcoming and year views, natural-language quick add, backlog,
  notes, ratings, reminders, metadata lookup, import/export and local backups.
- Include optional one-way Slate → Google Calendar sync on Windows using the
  user's own Desktop OAuth client. No two-way sync or hosted calendar service.

See [GitHub Releases](https://github.com/SPARTANAC95/slate/releases) for installers
and the original release notes. Version numbers describe application releases;
documentation updates do not create a new binary release.
